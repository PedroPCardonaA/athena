Settings

Connect an AI agent (MCP)

Athena speaks the Model Context Protocol, so agents can read your projects and ideas, add sources, and write summaries. There are no tokens: the agent runs a small command inside your local container.

Claude Code

claude mcp add athena -- podman exec -i athena python -m app.athena_mcp

Codex

codex mcp add athena -- podman exec -i athena python -m app.athena_mcp

Cursor, Windsurf, Gemini CLI, Claude Desktop (JSON)

{"mcpServers": {"athena": {"command": "podman",
  "args": ["exec", "-i", "athena", "python", "-m", "app.athena_mcp"]}}}

Read-only access: append --read-only to the command so the agent cannot change anything. Prompts such as research_idea, summarize_project and improve_idea appear in clients that support MCP prompts (in Claude Code: type /mcp__athena__).
